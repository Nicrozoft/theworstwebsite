# 阳光第三中学 · 学生公开信息系统（theWorstWebpage）

一个"常见场景 + 刻意做坏"的示范网站：学校的公开信息系统，共 9 个页面。
**所有 Bug、所有辣眼睛的配色，全部是故意设计的**，请勿模仿到真实项目中。

> [!WARNING]
> 本项目**以最坏的方式**示范了大量真实的低级错误，仅供教学、娱乐与反面对照。
> 请勿将其中任何做法（包括但不限于：明文存储密码、公开他人密码、GET 提交敏感信息、
> 比错字段的校验、永不增长的失败计数器等）用于任何真实系统。

> 设计原则：**界面文案一律是一本正经的学校系统口吻，绝不点破 Bug 的存在**。
> 所有荒谬之处都由系统的实际行为呈现，页面上找不到"bug""特性""故障"之类的字样。
> Bug 素材大量参考了互联网上流传的经典初级错误（字典序排序、差一错误、客户端单端校验、maxlength 与校验规则不一致、定时器叠加、数字精度丢失等）。

## 如何运行

纯静态网站，无需安装任何依赖，二选一：

- 直接双击 `start.bat`（会用默认浏览器打开首页）；
- 或双击 `index.html`；
- 或在本目录起个静态服务器：`python -m http.server 8080`，然后访问 <http://localhost:8080>。

> 建议用 Chrome / Edge 打开。数据存在浏览器 localStorage 里，想"恢复出厂设置"可在控制台执行 `SchoolDB.reset()` 后刷新。
> `images/` 目录故意不存在——师资照片、二维码、地图等破图是设计的一部分。

## 故意 Bug 清单（共 69 个）

### 一、逻辑错误（1-16 号，登录/注册/成绩/公告页）

1. **密码全校不能重复，重复了就告诉你谁在用**（注册页）：输入 `123456` 失焦即提示"该密码已被 张三（学号 20230101）、李四（学号 20230102） 使用，请更换密码。"——隐私泄露 + 荒谬业务规则双重暴击。
2. **"用户名已被占用"逻辑被误用到性别上**（注册页）：性别像用户名一样做全校唯一性校验，而"男""女"两个值都已被在校生"注册"，于是无论选哪个都会得到经典的"该性别已被占用，请更换后重试。"——注册永远过不了这一关。
3. **登录校验比较错了字段**：密码栏填"用户名"才能登录（如 用户名 `zhangsan` + 密码 `zhangsan`），正确的密码永远登不进去，报错文案却是正经的"用户名或密码错误"。
4. **登录失败计数器永不增长**：永远显示"还可以尝试 999 次"。
5. **验证码永远错**：校验时用的是"当下重新随机的一道验证码"，和页面显示的那张无关；但勾选"我是老师"且验证码留空可绕过。
6. **密码输入框 `maxlength=5`**，注册页却要求至少 6 位，两个页面互相矛盾且都振振有词。
7. **确认密码校验条件写反**：填相同会报"两次输入的密码不一致，请重新输入"，填不同反而通过。
8. **学号校验自相矛盾**：提示"必须为 8 位数字"，实际按 9 位校验，报错也理直气壮。
9. **学号查重、用户名查重全部比错字段**：学号拿去和"姓名"比，用户名拿去和"密码"比，查重形同虚设。
10. **入学年份必须 ≥ 2028**：不招收"过去"的学生。
11. **注册成功后学号被系统随机改掉**，并一本正经地通知"原学号作废，请牢记新学号"。
12. **成绩查询错位**：查 20230101（张三），标题显示的却是李四的姓名班级（展示的是"下一位同学"）；查不到的学号在报一句"未查询到"之后，照样渲染出第一位同学的完整成绩单。
13. **平均分除以（科目数 + 2）**，排名永远是"第 1 名（共 1 人参与排名，含校长）"。
14. **及格线颠倒**：<60 分显示"优秀"，≥90 分显示"不及格"。
15. **公告日期随机生成**（如 `2026-41-09`），"置顶"公告排在最后。
16. **公告"收起"按钮实际是复制**，越收越多；"更多通知"按钮只会追加同一条温馨提示。

### 二、隐私泄露（17-20 号，都是故意的）

17. **忘记密码 = 公开密码**：输入学号直接显示该生密码；学号留空点确定则公示全校密码表（文案正经："仅供本人查询，请勿外传"）。
18. **"记住密码"明文写入 localStorage**，且下次访问把**密码回填进用户名框**。
19. **成绩查询无需登录**，任何人可查任何人，页面还把"无需登录"当卖点标注。
20. **"导出成绩单"导出的是全校成绩 + 账号密码**：按钮和文件名看起来完全正常（`全校成绩单.txt`），内容却是全校泄露包。

### 三、版面 / 位置错误（21-28 号）

21. 登录框整体绝对定位在页面右侧 56% 处，"密码"标签被甩到面板外约 190px 的地方悬空。
22. 成绩条形图按 3 倍长度绘制，溢出 150px 的槽位，直接压到右侧的分数和评价上。
23. 成绩表/密码公示表表头整体错位 30px。
24. 公告第二条倒挂 180° 显示；第三条被绝对定位甩到面板背后，被后续公告遮住（神秘失踪）。
25. 页脚固定悬浮 108px 高，直接盖住正文底部内容。
26. "登录/注册"提交按钮 hover 时会跑路（位移 + 旋转），很难点到。
27. 右下角"在线客服"窗口关不掉：点 × 只会"为您调整窗口位置"，4 次后提示"当前坐席全忙，窗口暂不支持关闭"。
28. 顶部标题闪烁、走马灯、面板随机倾斜。

### 四、师资队伍页（29-35 号）

29. **工号按字典序排序**：工号是字符串，直接默认 `sort()`，"从小到大"排成 **1, 10, 11, 2, 3**——JavaScript 最经典低级错误。
30. **教师照片全是破图**：`src` 指向从未上传的 `images/teacher*.jpg`（图片忘了传/路径写错经典事故）。
31. **"查看简介"显示的是下一位老师的简介**（循环下标差一）。
32. **教师邮箱域名是 `qq.con`**（少打一个 m 的经典笔误），mailto 点击无法送达。
33. **职称徽章绝对定位悬浮**，压在姓名上并冲出卡片边缘。
34. **教师人数对不上**：页面声称"我校现有在职教师 10 人"，实际列出 5 位（硬编码数字忘了改）。
35. **教师搜索比错字段**：输入框写着"请输入教师姓名"，实际拿输入值与**工号**做精确匹配——搜"王"提示"未找到该教师"，搜"10"反而能找到王老师。

### 五、课表查询页（36-43 号）

36. **"今日"高亮差一列**：直接拿 `getDay()`（周日=0）当列下标，永远高亮隔壁那天——周五高亮"周六"，周日高亮"周一"，页面上"绿色底为今日课程"的说明一本正经。
37. **课程时间重叠 + 穿越**：每节"上课 50 分钟"但 45 分钟就开始下一节（8:00-8:50、8:45-9:35……全部叠车）；晚自习最后一节上到 **25:40**。
38. **周次是负数**：开学日期被填到未来，页面显示"当前是本学期第 **-4** 周"。
39. **下午课表叠在上午课表上**：负外边距导致两张表直接重叠，第 4 节被"下午与晚自习课程"标题盖住。
40. **点任何课程，上课地点都是"操场"**（数据 key 错位，全部命中同一条）。
41. **单元格窄列 + `white-space: nowrap`**：列宽 52px 又禁止换行，内容挤压溢出面板。
42. **切换班级完全不生效**：选初三(2)班、初三(3)班，展示的永远是初三(1)班课表，只补一句"其他班级课表数据建设中"。
43. **"刷新课表"丢失参数**：按钮写死跳回 `timetable.html`，地址栏里已选班级直接丢掉。

### 六、校园风采页（44-50 号）

44. **定时器叠加**：每点一次"下一张"就 `setInterval` 一个新定时器且从不清除——连点三下后轮播自动加速失控，实测计数一路飙到"第 19 / 共 5 张"还在涨。
45. **翻页无回绕**：计数能超过总数（第 19 / 共 5 张），"上一张"也能点到负数；越界后视口一片黑，页面照常显示计数。
46. **圆点数量对不上**：5 张图片只有 4 个圆点指示器（数量硬编码）。
47. **"自动播放"开关逻辑写反**：取消勾选反而开启 0.5 秒/张的极速播放，勾选才是停止。
48. **灯箱遮罩盖不住页脚**：遮罩 z-index 500，低于页脚的 600 和客服窗的 999——大图浏览时页脚和客服窗浮在遮罩上面。
49. **图片说明错位**：说明文字数组和图片顺序差一位，"教学楼"的图配的是"图片说明：食堂"。
50. **圆点错位**：点第 N 个圆点，显示的是第 N+1 张图。

### 七、意见箱（51-57 号）

51. **手机号永远不合法**：输入框 `maxlength=10`，校验却要求 11 位——只要填了就报"手机号格式不正确"；留空反而能正常提交。
52. **留言时间显示毫秒时间戳**：`留言时间：1789076932295`，原样直出 `Date.now()`。
53. **敏感词过滤误伤**：按单字替换，"差"字全部变"*"——"食堂菜品质量有点差"展示为"有点\*"，"操场跑道有点差"同样遭殃。
54. **字数统计按字节算**：一个汉字占 3 个"字"，限制"10 字"，输入 5 个汉字就红字提示"已超出字数限制"（但完全不阻止提交）。
55. **提交成功却看不到留言**：先渲染旧列表再保存，只能提示"提交成功！请刷新页面查看您的留言"。
56. **"最新留言"按从旧到新排**：排序方向写反，新留言永远垫底。
57. **表单用 GET 提交**：姓名、手机号、留言内容全部明文暴露在地址栏 `?name=…&phone=…&message=…` 里，长留言还会被截断。

### 八、联系我们（58-64 号）

58. **页面标题是"Untitled Document"**：建页工具的默认标题忘了改。
59. **招生热线变科学计数法**：热线号码被当成数字存储，显示为 `4.0080012345678903e+24`（Excel 导手机号经典事故）。
60. **咨询专线精度丢失**：`12345678901234567890` 显示成 `12345678901234567000`（超出 JS 安全整数范围，末尾悄悄变了）。
61. **二维码和位置示意图全是 404 破图**。
62. **"复制学校地址"复制的是客服电话**，并且无论成败都提示"学校地址已复制到剪贴板！"。
63. **办公时间表有两个"星期五"**（复制粘贴忘记改），且周六休息、周日反而 8:00-17:00 上班；表头还借用了成绩页的"整体错位 30px"样式。
64. **监督邮箱 `info@school`**：域名不完整，mailto 链接无法使用。

### 九、既有页面追加（65-69 号）

65. **首页每次加载都弹欢迎 alert**（`<body onload>`），关一次弹一次。
66. **首页"学校官方网站"链接拼错域名**：实际域名是 `worstsite.nicrozoft.org`，页面却写成 `worstslte.nicrozoft.org`——"site" 拼成了 "slte"，官方站点链接拼错域名的经典事故，点进去自然不是学校官网。
67. **密码强度条完全颠倒**：输入 2 位显示"非常强"（绿色），输入 16 位显示"极弱"（红色）。
68. **成绩导出三连确认**：点"导出成绩单"要连过三道 `confirm` 弹窗才真的开始导出。
69. **公告搜索比错字段**：搜索框让用户"输入关键词"，实际拿关键词去匹配一条**随机生成的日期字符串**——搜"考试"永远"未找到"，能不能搜到全看运气。

### 十、配色怪异（观感不适）

- 荧光绿底 + 青色/品红圆点纹理背景；品红页头配绿色标题 + 蓝黄双色描边阴影；
- 青色输入框配红字；红底绿字按钮（hover 变蓝底红字）；
- 黄色面板 + 品红双线边框 + 青色虚线外框 + 红色硬阴影；
- 红底黄字波浪抖动错误框；绿底品红字成功框；彩虹滚动字色 + 全站闪烁元素；
- Comic Sans MS / 楷体 / 华文彩云（空心字）混排。
